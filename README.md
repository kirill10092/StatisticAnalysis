# Лабораторная работа №3

## Тема

Системы контроля версий Git.

## Участники команды

* Семибратов Кирилл — вариант 16: доля плохих дорог по субъектам России
*  Голиков Роман — вариант 6: миграция населения России

## Используемые технологии

* C#
* Windows Forms
* Git
* GitHub
* Visual Studio

## Структура веток

* `master` — главная стабильная ветка проекта.
* `dev` — общая ветка разработки.
* `feature/kirill` — ветка разработки варианта Кирилла.
* `feature/roman` — ветка разработки варианта Романа.

## Вариант Кирилла

Реализована работа с данными о доле плохих дорог по субъектам России за последние 15 лет.

### Функционал:

* загрузка CSV-файла;
* вывод данных в таблицу;
* построение графиков зависимости доли плохих дорог от года;
* вычисление субъекта, где процент плохих дорог максимально уменьшился;
* вычисление субъекта, где процент плохих дорог минимально уменьшился;
* прогнозирование методом скользящей средней на последующие N лет.

## Вариант Романа

Реализована работа с данными о миграции населения России за последние 15 лет.

### Функционал:

* загрузка CSV-файла;
* вывод данных в таблицу;
* построение графиков зависимости числа иммигрантов и эмигрантов от года;
* вычисление максимального процента изменения миграции за год;
* прогнозирование методом скользящей средней на последующие N лет.

## Работа с Git

В ходе выполнения лабораторной работы использовались:

* отдельные ветки для каждого участника;
* коммиты;
* Pull Request в ветку `dev`;
* review кода коллег;
* merge веток после проверки;
* финальное объединение `dev` в `master`.

## Запуск проекта

1. Открыть файл решения `.sln` в Visual Studio.
2. Запустить проект.
3. Выбрать нужную вкладку.
4. Загрузить CSV-файл.
5. Построить график и выполнить прогноз.
